Routing Layers
Currently, we only accept the subcircuit and hierarchy (partitioning) information in form of pre-defined JSON data. These information will be used to group the components in the same subcircuit together and do the floorplanning for each subcircuit separately.

The LLM-generated constraints should be in the format of a list of tuples, where each tuple represents a constraint. The first element of the tuple is the constraint name (a string), followed by the target component (a string), and then the related components (one or more strings).

User can manually add more constraints using the similar constraint format as in the LLM tab.

The User-defined constraints should be in the format of a list of tuples, where each tuple represents a constraint. The first element of the tuple is the constraint name (a string), followed by the target component (a string), and then the related components (one or more strings). In addition, don't include trailing commas in the list of tuples.

The orientation constraints should be in the format of a dictionary, where the key is the component name (a string), and the value is either 0 or 1. Following is the gallery for reference: (notice that we only show for MOS transistors and resistors, however, the orientation definitions are similar for other BJT transistors and components (e.g., capacitors)).

How to use: Load SPICE netlist using the "File" menu, specifiy all the constraints (heuristic, path-based, subcircuit-based, LLM-generated, and user-defined) using the right panel. Once all the constraints are specified, click the Generate Schematic button to generate the schematic. The generated schematic will be displayed on the left canvas. You can also export the generated schematic in JSON format by clicking the Export Schematic button.

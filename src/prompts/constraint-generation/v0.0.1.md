You are an experienced analog designer. We are dealing with the design task of translating SPICE netlist into the corresponding schematic.
The schematic generation is formulated as a constraint generation task with the initial schematic is just an empty gird. From that,  we want to generate a list of placement constraints, for example: ("M1", "same_row", "M2") which means we want to place transistor M1 and M2 in the same row in our grid-based schematic canvas or ("M5", "right_of", "M4") which means we want to place transistor M5 on the right side of the transistor M4.

After having a list of these constraints, we then use a constraint programming solver to find the optimal position (i.e., which row and column) of each component in the SPICE netlist.

Your task is to generate these list of constraints as the input for constraint programming solver based on the given SPICE netlist, the building block structure recognition results (buiding blocks and the components belong to the same block) and the partitioning results (e.g. amplification stages, biasing stages). The generated constraints should follow the format:

constraints = [
    ("name of component 1", "relationship", "name of component 2"),
    ("name of component 1", "relationship", "name of component 2"),
    ("name of component 1", "relationship", "name of component 2"),
    ...
]

The names of components should use the exact names defined in the SPICE netlist (with the same lowercase, uppercase). The relationship attribute should be one of the following pre-defined relations:

- same_row
- same_column
- below
- above
- left_of
- right_of
